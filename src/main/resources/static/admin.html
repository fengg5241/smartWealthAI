📖 WeChat Work Bot Setup Guide

This is a one-time setup done by you or your client's WeChat Work admin. Takes about 5 minutes.

Step 1: Open WeChat Work Admin

Visit work.weixin.qq.com → Log in as admin → App Management (应用管理) → Create App (创建应用) in the bottom section (Self-built Apps).

Step 2: Get CorpID

At the very bottom of the App Management page, find "My Company" (我的企业) → copy the CorpID (企业ID) at the bottom. This is your company's unique identifier (starts with ww).

Step 3: Get Secret

In the app's settings page, find Secret → click "View" → copy it. This is the API secret used to download files sent to the bot.

Step 4: Configure Callback URL

In the app settings, find "Receive Messages" (接收消息) → enable it → set:

URL: https://你的域名/api/wecom/callback

Token: Click "Random Generate (随机获取)" — copy this value

EncodingAESKey: Click "Random Generate (随机获取)" — copy this value

⚠️ Do NOT click Save yet — you need to set the env variables first and restart the service, otherwise the URL verification will fail.

Step 5: Set environment variables & restart

Add to your .env or server config:

WECOM_ENABLED=true
WECOM_CORP_ID=<paste CorpID>
WECOM_TOKEN=<paste Token>
WECOM_ENCODING_AES_KEY=<paste EncodingAESKey>
WECOM_SECRET=<paste Secret>

Restart your SmartRAG service.

Step 6: Verify & Save

Go back to the WeChat Work admin page → click Save. WeChat Work will send a GET request to verify the URL. If the service is running, it should pass.

Step 7: Link to a tenant

Back in the IM Bot Mappings section below: select WeChat Work → paste the CorpID → select a tenant → click Save.

Step 8: Add bot to group chat

In WeChat Work, open the app page → Add to Chat (添加到聊天) → select the group → done. Now users can @mention the bot and upload files.

💡 Need help? If the client can't do this, offer to walk them through it via screen sharing in 10 minutes.

📖 Slack Bot Setup Guide

Slack uses standard OAuth — no copying keys. Setup is done once by you, then customers self-serve.

Step 1: Create Slack App

Go to api.slack.com/apps → Create New App → From scratch → pick a name (e.g. "SmartRAG") → choose your workspace.

Step 2: Configure Slash Command

Left sidebar → Slash Commands → Create New Command:

Command: /ask

Request URL: https://你的域名/api/slack/commands

Short Description: Ask questions about your documents

Step 3: Enable Events

Left sidebar → Event Subscriptions → enable:

Request URL: https://你的域名/api/slack/events

Subscribe to bot events:

  • app_mention — when someone @mentions the bot
  • file_shared — when someone uploads a file

Step 4: Configure OAuth & Permissions

Left sidebar → OAuth & Permissions → add Redirect URL:

https://你的域名/api/slack/oauth/callback

Add Bot Token Scopes:

  • chat:write — send messages
  • commands — slash commands
  • files:read — download uploaded files
  • app_mentions:read — detect @mentions

Step 5: Set environment variables & restart

From Basic Information → App Credentials, copy the values:

SLACK_ENABLED=true
SLACK_CLIENT_ID=<paste Client ID>
SLACK_CLIENT_SECRET=<paste Client Secret>
SLACK_SIGNING_SECRET=<paste Signing Secret>
SLACK_BOT_TOKEN=<OAuth → Bot User OAuth Token>

Restart your SmartRAG service.

Step 6: Customer self-serve

From Manage Distribution → copy the "Add to Slack" button HTML, or give the customer this URL:

https://slack.com/oauth/v2/authorize?client_id=<CLIENT_ID>&scope=chat:write,commands,files:read,app_mentions:read

Customer clicks the link → picks their workspace → clicks Allow → done in 30 seconds. No tech skills needed.

Step 7: Link to a tenant

After the customer installs, you'll see the Team ID in the OAuth callback. Go to IM Bot Mappings below: select Slack → paste Team ID → select the customer's tenant → Save.

✅ Slack is the easiest. Once configured, customers install it themselves with zero technical steps.
